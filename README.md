# «До верхньої полиці»

**Грати: https://makrosxd.github.io/robot_jump/**

Стрибалка в стилі гри [«Один на зміні»](https://dn220585sni.github.io/bot_alone): той самий
робот, таблетки з личками, кольори й шрифт — але замість ловити таблетки робот скаче
поличками аптеки дедалі вище.

Гра — три статичні файли (`index.html`, `game.js`, `fonts/`), без збірки й залежностей.
Працює з будь-якого статичного хостингу (GitHub Pages) і просто з диска.

## Правила

- Робот підстрибує сам; гравець лише веде його ліворуч-праворуч. Екран замкнений у кільце:
  вийшов за лівий край — з'явився з правого.
- Біла поличка — звичайна, жовта — їздить, пластир витримує один стрибок, пружина підкидає.
- Таблетка — +5, вірус, на якого стрибнули згори, — +10. Зачепив вірус боком чи знизу — кінець.
- Вітамін — ривок угору на 2,3 с; віруси на шляху розлітаються.
- Рахунок — висота (30 px = 1 бал) плюс бонуси. Рекорд зберігається в браузері.
- Поличок мало: зазвичай одна на ряд, проміжок 150–270 px за стрибка 306 px — до наступної
  завжди можна дострибнути, але запасної майже ніколи нема.

## Керування

| Де | Як |
|---|---|
| Клавіатура | `←` `→` або `A` `D`; `P` / `Esc` — пауза; `M` — звук; `Enter` — грати |
| Телефон | кнопки ◀ ▶ у нижніх кутах (спрацьовує вся ліва чи права половина екрана) |
| Телефон, нахил | кнопка «Керування: нахил» на старті (на iPhone спитає дозвіл на датчики) |

## Перевірка на своєму ПК

```bash
node tools/serve.mjs
```

Відкрити `http://localhost:8770/`. У консолі є гачок `__polytsia`: стан `__polytsia.S`,
`__polytsia.sim(мс, ai)` проганяє симуляцію без малювання — так перевірялись генератор
(найбільший проміжок між поличками 270 px за стрибка 306 px), досяжність (бот, що в момент
відштовхування обирає найвищу поличку, до якої встигає, без вірусів долазить до 80 тис. px)
і зіткнення.

## Нова версія

Номер версії стоїть у трьох місцях і має збігатися: `VERSION` у `game.js`, `version.json`
і `game.js?v=N` в `index.html`. GitHub Pages дозволяє браузеру 10 хвилин тримати сторінку
в кеші, а телефон повертає вкладку з пам'яті взагалі без запиту, тому гра сама читає
`version.json` повз кеш (на старті, при поверненні на вкладку, після кінця партії) і, якщо
на сайті версія новіша, перезавантажується за адресою з `?v=N`.
